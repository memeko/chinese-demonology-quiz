# Тест по демонологии Китая

Мобильный тест на чистых HTML, CSS и JavaScript. Подходит для GitHub Pages и Telegram Web App.

Доступны два режима:

- обычный тест из 33 исходных вопросов;
- «Экзамен на заклинателя» из 50 случайных вопросов без повторов. Общая база экзамена содержит 152 задания: 32 исходных и 120 дополнительных вопросов по китайской демонологии и традициям.

## Локальный запуск

```bash
python3 -m http.server 8080
```

Откройте `http://localhost:8080`.

## Telegram Web App

После публикации укажите HTTPS-адрес страницы в BotFather через `/newapp` или настройку Menu Button.
