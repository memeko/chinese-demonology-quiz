# Тест по демонологии Китая

Мобильный тест на чистых HTML, CSS и JavaScript. Подходит для GitHub Pages и Telegram Web App.

## Локальный запуск

```bash
python3 -m http.server 8080
```

Откройте `http://localhost:8080`.

## Telegram Web App

После публикации укажите HTTPS-адрес страницы в BotFather через `/newapp` или настройку Menu Button.
